# Snitap - Landing Page de Patins

Landing page responsiva e animada para a Snitap, uma marca de patins com uma identidade visual colorida, divertida e dinâmica.

## Sobre o projeto

A página apresenta:

- Hero section com chamadas para compra e vídeo;
- Animações de entrada dos patins, estrelas e palavras em destaque;
- Banner horizontal com rolagem contínua;
- Galeria de fotos com referências do Instagram;
- Footer com navegação e links para redes sociais;
- Layout responsivo para dispositivos móveis, tablets e desktops.

## Tecnologias

- HTML5;
- CSS3;
- CSS custom properties;
- CSS animations e media queries;
- Google Fonts: Syne, Montserrat e Inter.

## Como executar

Este é um projeto estático, portanto não precisa de instalação de dependências ou processo de build.

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.

Para uma experiência melhor durante o desenvolvimento, abra a pasta no VS Code e use uma extensão como **Live Server** para executar a página com recarregamento automático.

## Estrutura

```text
.
├── index.html
├── assets/
│   ├── icons/
│   ├── images/
│   ├── banner.svg
│   ├── Ellipse.svg
│   ├── Logo.svg
│   ├── patins-image.png
│   ├── Stars 1.svg
│   └── Stars 2.svg
└── styles/
    ├── banner.css
    ├── footer.css
    ├── galery.css
    ├── global.css
    ├── header.css
    ├── hero.css
    └── index.css
```

O arquivo `styles/index.css` reúne os estilos da página por meio de imports, enquanto cada arquivo CSS é responsável por uma seção específica.
