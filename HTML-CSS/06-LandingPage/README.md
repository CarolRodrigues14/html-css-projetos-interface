# Zinger - Landing Page

Landing page de um aplicativo de karaokê chamada **Zinger**, desenvolvida com HTML e CSS puro.

## Descrição

A página apresenta uma proposta de produto para um app de música e karaokê com:

- Hero section com destaque para a marca e CTA;
- Seção de apresentação do aplicativo;
- Cards de funcionalidades;
- Planos e preços;
- Área de download;
- Footer com navegação e redes sociais.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Ícones e imagens locais no diretório `assets`

## Como executar

### Opção 1
Basta abrir o arquivo `index.html` no navegador.

### Opção 2
Se quiser rodar em um servidor local:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Observações

Este projeto é uma landing page estática, sem backend ou dependências externas de instalação.
